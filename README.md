Sobre o projeto

O site transforma temas de segurança, saúde, ergonomia, prevenção e responsabilidade em uma experiência interativa. Os participantes podem explorar o conteúdo, jogar, acumular pontos e acompanhar seu desempenho.

O projeto foi desenvolvido por alunos do Formare, dentro da Cummins de Osasco.

Funcionalidades

Central de jogos educativos.

Pontuação e ranking competitivo.

Projeto 3D de um ambiente industrial.

Conteúdo sobre Red Flag.

Mural “Voltar Seguro para Casa”.

Conteúdo sobre segurança, saúde, ergonomia e prevenção.

Experiência responsiva para celular, tablet e computador.

Jogos

1.
Quiz de Segurança — Red Flag, EPIs, LOTO e comunicação de riscos.

2.
Desafio Fábrica Eficiente — 5S, Kaizen, Kanban, melhoria contínua e qualidade.

3.
Ache o Erro — identificação de atos e condições inseguras.

4.
Organize a Fábrica — organização, fluxo e princípios Lean.

Projeto 3D

O site apresenta um ambiente industrial em 3D, com exploração por:

Arraste para girar.

Zoom com mouse ou gesto de pinça.

Modo de tela cheia.

O objetivo é aproximar o aprendizado da realidade industrial e tornar a SIPAT mais interativa.

Mural “Voltar Seguro para Casa”

Espaço para os participantes compartilharem frases sobre:

•
Por quem se cuidam.

Para quem desejam voltar seguros.

O que os motiva a praticar segurança.

O mural conecta a segurança às pessoas, famílias, sonhos e motivos de cada participante.

Execução local

Os comandos abaixo são um modelo para projetos web com Node.js. Ajuste conforme o package.json do repositório:

Bash


npm install
npm run dev



Depois, abra a URL local exibida no terminal, geralmente http://localhost:3000.

Boas práticas

Antes de publicar alterações:

•
Teste em celular e desktop.

Verifique acessibilidade e contraste.

Confirme se os jogos e o ranking funcionam.

Evite dados pessoais ou informações institucionais não autorizadas.
